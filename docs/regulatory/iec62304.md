# IEC 62304 note (portfolio)

## Classification (hypothetical)

If this were medical device software, geometry conversion and series validation affecting spatial correctness would likely fall under **IEC 62304 Class B** (injury possible but not life-threatening if failures are controlled). Clinical planning integration could push **Class C**.

**This repository is not claiming Class B compliance.** It demonstrates the *shape* of artifacts auditors expect.
